Same studio as a link, different tab. Use it for a report, a press release, a
recipe, a menu — anything already written down.

## Do it

1. **Create** → **Post** → **Article Carousel**.
2. Pick your **Account**. Nothing appears until you do.
3. Choose the **📄 File** tab.
4. Drop your file on the zone, or click to browse. **PDF, JPEG or PNG, up to 25
   MB.**

5. Once it is chosen, the zone shows its name and size.
6. Set **Language**, **Slides**, **Character** and **Template**.
7. **✦ Generate Carousel**.

## What it does with the file

It reads the text and writes slides from it — it does not simply cut the PDF into
pictures. A ten-page report becomes however many slides the content warrants, in
your voice, on your template.

## If the result is thin

Usually the file was mostly pictures with little text. Two things help:

- Set **Slides** to a specific number rather than Auto, so it has to fill them.
- Use the **✏️ Prompt** tab instead and describe what the document says.

## Note

Unlike the link tab, there is no *use images from the article* here — a PDF's
pictures are not pulled out. Put pictures on the slides yourself with
[Replace a picture](/learn/create/replace-a-picture/).
