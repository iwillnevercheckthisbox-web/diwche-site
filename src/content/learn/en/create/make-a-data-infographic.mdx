## Do it

1. **Create** → **Post** → **Data Infographic**.
2. Choose **Standard** or **Freestyle**.
3. Pick a **Visual Theme**.
4. Give it a source: **🌐 URL** or **✏️ Prompt**.
5. Set **Language**, **Slides**, **Character** and **Account**.
6. **✦ Generate Infographic**.

## Standard or Freestyle

**Standard** uses one consistent layout throughout. Predictable, and it looks
like a set.

**Freestyle** picks the best layout for each slide on its own — timeline,
leaderboard, donut, comparison, hero stat, scatter — with the theme held constant
across all of them. Better when your numbers are of different shapes.

## No file tab here

This one takes a **link or a prompt only**. There is no PDF upload — for a
document, use [Article Carousel](/learn/create/carousel-from-a-file/) instead.

## Writing the prompt

Give it the actual figures, or a page that has them:

> Iranian population in Austria 2024 — demographics, employment rate, asylum
> statistics.

## Photos in between

On the URL tab, **Use images from article** downloads the article's photographs
and interleaves them as full-bleed slides. On the Prompt tab, **📸 Add Photos**
does the same with your own.

## Afterwards

**✎ Edit Text** per slide, **Switch Theme** then **↺ Apply Theme**, a caption,
then **📲 Post as Carousel**, **🎵 Post as Reel**, **⬇ Download** or **💾 Save as
Draft**.

There is no per-slide image replacement here — that exists only on Article
Carousel.
