Characters are who writes. Every caption, script, title and comment reply comes
from one, and they sound different from each other.

## Adjust one

Open a character. Five sections:

**Identity** — the personality dials. Move them and the writing moves with them.

**Extra notes** — free text. The most direct control you have. Things like *never
use exclamation marks*, *always name the museum*, *say "picture", not "artwork"*
go here and are obeyed.

**Voice expression tags** — how the character sounds when it is *spoken*, for
reels and voice-over: where it pauses, what it emphasises.

**Photo** — a face, from a file or **From Gallery**.

**Speaking voice** — the synthesised voice used when this character narrates.

**↺ Reset to default** puts a character back.

## Read the writing instructions

At the bottom, **Writing instructions** shows — read only — exactly what is
handed to the writer for this character. If a character is not sounding the way
you expect, read this: it is the actual brief, and it usually explains it.

## Where they get used

- **Account Identity** → the default for that account
- **Comment Auto-Reply** → **Who answers**
- Every studio has a **Character** dropdown, preset to the account's default

## Which to pick

Match the character to the *format*, not just the page. Sharp works in a caption
and badly in a reply to a follower's question. Many pages use one character for
posts and a warmer one for comments.
