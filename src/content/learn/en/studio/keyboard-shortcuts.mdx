## Learn these five first

| Key | What it does |
| --- | --- |
| **Space** | Play and pause |
| **S** | Split at the playhead |
| **A** / **T** | Select tool / Trim tool |
| **Shift + Delete** | Delete and close the gap |
| **Alt** (held) | Ignore snapping while dragging |

## Everything

| Command | Windows | Mac |
| --- | --- | --- |
| Play / pause | Space | Space |
| Delete, leaving a gap / ripple delete | Delete / Shift + Delete | Delete / Shift + Delete |
| Split at playhead | S | S |
| Select tool / Trim tool | A / T | A / T |
| Duplicate | Ctrl + D | Cmd + D |
| Step one frame / one second | ← → / Shift + ← → | ← → / Shift + ← → |
| Start / end | Home / End | Home / End |
| Marker / In / Out / clear range | M / I / O / X | M / I / O / X |
| Zoom timeline / fit | + − · Ctrl + wheel · Shift + Z | + − · Cmd + wheel · Shift + Z |
| Add to selection | Shift / Ctrl + click | Shift / Cmd + click |

| Cut, leaving a gap / ripple cut | Ctrl + X / Ctrl + Shift + X | Cmd + X / Cmd + Shift + X |
| Undo / Redo | Ctrl + Z / Ctrl + Shift + Z | Cmd + Z / Cmd + Shift + Z |
| Select all / deselect all | Ctrl + A / Ctrl + Shift + A | Cmd + A / Cmd + Shift + A |

## Markers and range

**M** drops a marker at the playhead — click it to jump back, double-click to
remove it. **I** and **O** set an In and an Out point, which draws a band on the
ruler and lets you export just that stretch. **X** clears the range.
